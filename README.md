# Geoscience 공동탐구

인천 지역 포장 표면의 반사율과 수분 공급이 열환경에 미치는 영향을 계절별 기상 조건에서 시뮬레이션하는 프로젝트입니다.

**현재 상태(2026-09-26): 두 층 계산 엔진과 실제 인천 기상 입력 연결 구현.** 위층 5 cm는 보수재 충전 콘크리트 WCC로 정했습니다. 재생 쇄석 지지층은 아직 후보입니다. [모델 코드](src/geoscience/model.py)는 열수지·증발·양방향 물 이동·일정 배수·유출을 계산하며, [기상 연결기](src/geoscience/weather.py)가 실제 시간자료를 [실행기](src/geoscience/simulate.py)에 붙입니다. **WCC 전체 물성은 아직 완성하지 못했으므로 인천 WCC 냉각 예측 결과는 없습니다.**

이번 [기상 연결 결과·실행법](docs/weather-integration.md)과 [추가 확보한 WCC·RCA 원저](docs/wcc-source-search-2026-09-26.md)를 우선 읽습니다. 실제 원본 8,736시간, 공식 일강수량 보조자료 182일을 사용했습니다. 1·2·7·8월 121개 날짜 후보 중 99개의 24시간 기상 입력을 구성했습니다. 이는 동결을 포함한 모델 적용성·WCC 물성까지 확정된 실험 일수는 아닙니다. 나머지 날짜는 누락·눈 등의 사유를 남깁니다.

[콘크리트 2층 모델 설명](docs/concrete-model-draft.md), [수식 PDF](output/pdf/concrete-model-draft.pdf), [편집용 LaTeX](docs/concrete-model-draft.tex)는 재료 선택 전 작성한 방정식 검토안입니다. WCC를 ‘추천’으로 적은 부분은 위의 사용자 확정으로 갱신합니다. 수치 적분의 현재 구현 방식은 아래 실행 설명을 따릅니다.

기존 계획의 7-8월 분석에 1-2월을 추가하고, 장비 부족으로 수행하기 어려운 시편 실험은 수치 검증, 민감도 분석, 불확실성 분석으로 대체합니다.

구현 순서, 물리 모델과 비교 조건은 [시뮬레이션 실행 계획](docs/simulation-plan.md)에 정리되어 있습니다. **최신 범위는 위 0–5 cm 다공성·보수성 콘크리트와 아래 5–30 cm 지지층**이며, 상세한 [층의 깊이·물 이동 검토안](docs/layer-water-review.md)과 [콘크리트 물성 근거 1차 점검](docs/concrete-parameter-review.md)을 우선합니다. 일정 하부 배수를 포함하고 동결 계산은 제외하며, 겨울은 건조 또는 비동결 적용 범위 안에서 평가합니다. 추가 기상자료 없이 개발을 시작하며, 강수·적설 판정이 불확실한 날은 적용 범위를 제한합니다. 수치 검증을 실제 포장 실험 검증과 동일하게 취급하지 않습니다.

날짜 선정, 06시 급수 절차, 3×3 요인 비교, 평가 지표와 심화 분석은 [수치실험 설계](docs/experiment-design.md)에 자세히 기술했습니다.

현재 입력 자료는 실제 기상 관측값을 포함하며, 인천 112의 기본 시뮬레이션에 사용할 수 있습니다. 계절 자료 점검은 [`docs/initial-review.md`](docs/initial-review.md), 2025년 연간 시간자료 점검은 [`docs/annual-data-review.md`](docs/annual-data-review.md)에 정리되어 있습니다.

1·2단계 진행 기록: [초기 보수적 전처리 기록](docs/preprocessing-rules.md), [선행연구·방정식 감사표](docs/model-literature.md), [원본 해시 목록](data/source_manifest.json). `preprocess.py`의 초기 QC 보존 결과에 `weather.py`가 공식 통계 규칙·야간 판정·일강수량 대조를 적용합니다. 최신 처리와 제한은 [기상 연결 설명](docs/weather-integration.md)을 따릅니다. 대용량 입력·결과는 로컬 `outputs/`에만 두며 사용자 원본은 수정하지 않습니다.

2026-09-25: [핵심 방정식과 논문별 근거](docs/core-equations.md)를 사용자 검토용으로 작성했습니다. 수식이 깨지면 [조판된 PDF](output/pdf/core-equations.pdf)를 읽고, 수정 가능한 [LaTeX 원본](docs/core-equations.tex)을 사용할 수 있습니다. 이 문서와 PDF는 **이전 세 상태·한 물 저장소 방정식안**으로, 최신 콘크리트+지지층 네 상태 모델의 완성본이 아닙니다. 보존식의 출처는 참고할 수 있지만 세라믹 재료 가정과 물성 근거는 새 [물성 감사표](docs/concrete-parameter-review.md)를 따릅니다. [열수지 유도 부록](docs/equation-derivation.md)에서 물의 열용량·증발 잠열·급수 에너지의 결합을 확인할 수 있습니다. 물성 수치는 아직 확정하지 않았습니다.

PDF 재생성: `node scripts/render_core_equations.mjs concrete-model-draft` 다음 `node scripts/print_equations.mjs concrete-model-draft`. 로컬 KaTeX와 Chromium을 사용한 PDF 조판이며, `.tex`는 별도 편집용으로 내보냅니다. XeLaTeX 컴파일 검증과 PDF 렌더링 검증은 서로 다릅니다.

## 실행과 검증

추가 패키지 없이 Python 3.10 이상에서 실행합니다.

```sh
python3 -m unittest discover -s tests -v
python3 -m src.geoscience.simulate examples/solver-smoke.json --output outputs/solver-smoke.json
```

예제는 **가상 입력을 사용한 코드 시험**입니다. 콘크리트 물성·저장 용량·물 이동 곡선·기상값을 WCC 실측값이나 인천 관측값으로 해석하지 않습니다. 결과 JSON에 입력과 이 경고가 함께 보존됩니다. 기존 결과 파일은 덮어쓰지 않습니다.

- 표면·아래층 각각의 온도와 물을 계산합니다. 아래층 물은 표면으로 이동한 다음 단계부터 증발에 쓰입니다.
- 살수·강수 유입, 증발·배수 유출, 층간 교환의 물과 에너지를 함께 기록합니다. 초과 유입은 유출량으로 남기고, 물이 없으면 증발·배수를 멈춥니다.
- 일정한 시간당 배수는 저장량의 비율 감소가 아닙니다. 상향 재공급을 끈 비교에서도 하향 이동은 유지됩니다.
- 시간 적분은 **보존형 1차 명시법 + 유속 제한**입니다. 검토안의 고갈 시점 사건 분할은 아직 구현하지 않았습니다. 한 단계 시작 시의 물을 경쟁 유출에 비례 배분하고, 새 유입수는 다음 단계에서 사용합니다. 기본 최대 간격은 수치 설정인 10초이며 열적 안정성에 따라 더 줄입니다. 20/10/5초 비교를 포함한 수렴 테스트를 통과했으나 실제 입력에서도 별도로 확인해야 합니다.
- 수분에 따른 열전도율·증발저항·흡인력·수리전도도는 입력한 곡선 안에서 선형 보간합니다. 범위 밖 외삽, 누락된 기상값의 0 대체, 자동 물성 대입을 하지 않습니다.
- 눈 또는 젖은 층의 0°C 이하 상태는 오류로 중단합니다. 온도를 0°C로 고정하지 않습니다.

현재 45개 테스트: 독립적인 두 열저장소 해석해 대조, 시간 간격 수렴, 1,000개 고정 난수 사례의 질량·에너지 보존, 물 고갈·용량 초과·유출수 혼합 열량·동결 범위·결측 입력과 기상 변환을 확인합니다. 추가로 `scripts/verify_weather.py`가 실제 기상과 가상 시험 재료를 연결하여 20/10/5초 보존·수렴을 점검합니다. 이는 **실제 WCC 검증이 아닙니다**. 시험 결과는 로컬 `outputs/`에 저장합니다.

## 이번 구현에 연결한 원문 근거

- [FAO-56, 3장 식 11·예제 3](https://www.fao.org/4/X0490E/x0490e07.htm): 포화수증기압 계산. 원문 예제 15°C·24.5°C 값을 자동 대조합니다. 일정 잠열 `2.45 MJ/kg`은 약 20°C 기준의 단순화이며 넓은 온도 범위에서 민감도 확인이 필요합니다.
- [NIST CODATA](https://physics.nist.gov/cgi-bin/cuu/Value?sigma): 복사 계산 상수 `5.670374419×10⁻⁸ W/(m²·K⁴)`.
- [Dong 등(2019), p.12, Table 2](https://doi.org/10.3390/ma12162546): 물 비열 `4174 J/(kg·K)`를 40°C 기준 고정 근사로 사용하며 변경 가능하게 했습니다. 같은 표의 포장재는 **아스팔트 모체의 SFWRP**이므로 그 밀도·열전도율·비열·보수량을 WCC에 대입하지 않았습니다.
- [Wang 등(2021), §3.4](https://doi.org/10.3390/ma14206141): 300×300 mm 시편에 500 mL 살수, 면적당 **5.56 L/m²**. 향후 살수량 비교의 문헌 참고점이며, 포화 보수량이나 최적량이 아닙니다. 시편 두께는 100 mm여서 우리 50 mm와 다릅니다.

원문과 추가 문헌을 확인했지만 선택한 WCC 전체의 건조 열용량·수분별 열전도율·유효 보수량·증발저항 곡선은 아직 한 배합의 입력 묶음으로 확보하지 못했습니다. 특히 [Wang 등(2022)](https://doi.org/10.1016/j.buildenv.2022.109083)은 공개 초록/노출 절에서 증발저항 회귀의 존재를 확인했으나 정확한 계수 원문은 확보하지 못했고, 그 시편도 일반 투수성 콘크리트입니다. **장파·대류 추정과 기상 연결은 이번에 구현했지만 해당 추정식의 인천 현장 보정은 아닙니다.** 후속 원저에서는 Con-W 유효 열물성과 RCA 수문 계수를 확보했으며, 같은 배합·건조 기준으로 합칠 수 없는 이유를 [자료 확보 기록](docs/wcc-source-search-2026-09-26.md)에 남겼습니다. 동일 WCC 정량 예측에는 원자료가 더 필요합니다. 대리값·가정 범위를 사용하는 비교·민감도 연구로 진행하려면 그 해석 범위를 먼저 인정해야 합니다.
