# WCC 부족 물성 후속 원문 확인

2026-09-26. **확정 입력 묶음이 아닌 출처 감사 결과.** 대상은 보수재 충전 다공성 **시멘트 콘크리트**이며, 세라믹·보수성 아스팔트의 값을 옮기지 않았다. 5 cm 위층과 25 cm 지지층의 네 상태 `Ts, Tb, Ws, Wb`를 유지하는 데 필요한 자료만 추적했다.

## 이번에 실제로 확보한 것

1. 동일 계열인 보수재 함유 시멘트 콘크리트의 **유효 열전도율·체적 열용량 묶음**과 살수 뒤 일별 증발효율을 추가 확보했다. Wang (2021)의 동일 배합 또는 건조 물성은 아니다.
2. RCA 지지층의 **포화 투수계수·보수곡선·불포화 투수 모형 계수**를 공개 원저에서 확보했다. 기존 Pham (2026) 열물성의 공극률과 새 수문 원저의 포화수분함량은 일치하지 않는다.
3. Wang WCC 전체의 건조 열물성·전체 저장량·증발저항 수분함수는 여전히 확보하지 못했다. 따라서 완성된 WCC 수치 설정이나 냉각 예측 결과를 만들지 않았다.

## 위층: 같은 재료 계열의 제한적 대리 근거

[Takebayashi & Moriyama (2012), DOI 10.1155/2012/523051](https://doi.org/10.1155/2012/523051), 공개 [원문 PDF](https://pdfs.semanticscholar.org/161a/45bfff4089fd7f196447d7bc803417c8c523.pdf).

Table 1(p.3)의 Con-W/Con-W′는 시멘트 콘크리트+액상 보수제 A/B이다. 세부 화학 조성·충전량은 제시되지 않아 Wang의 플라이애시/실리카퓸 충전재와 동등하다고 할 수 없다. 콘크리트층은 15 cm이고, 열물성은 표면 부근 관측의 역추정이다(§3.3, §4.2).

| 원문 위치 | Con-W | Con-W′ | 정의·제한 |
|---|---:|---:|---|
| Table 4, p.8: `k` | 1.19 W/(m·K) | 0.90 W/(m·K) | 열유속·온도 관측으로 추정한 유효값 |
| Table 4, p.8: `Cv` | 1.5 MJ/(m³·K) | 1.2 MJ/(m³·K) | **질량 비열이 아닌 체적 열용량**; 건조값 아님 |
| Table 3, p.6: 건조 알베도 | 0.202 | 0.150 | 표에 건조 조건 명시 |
| Table 5, p.8: `β`, 1/2/3일 | 0.04/0.03/0.03 | 0.04/0.02/0.02 | Jürges 열전달계수와 관측 일누적 증발로 추정 |
| Table 7, p.8: 다른 추정의 `β` | 0.044/0.027/0.030 | 0.051/0.023/0.024 | Eq.9 온도 계산 포함; Table 5와 혼합하지 않음 |

§3.1(p.2)의 방사율 `0.97–1.0`은 전체 시험 표면의 범위이며 Con-W 단독값이 아니다. §3.3(p.6)은 재료 내부 수분함량을 측정하지 않았다고 명시한다. 따라서 위 `Cv`에 `cw·Ws`를 더하면 수분 열용량을 중복 반영할 수 있다. `β`는 특정 살수 후 날짜별 값이며 `β(Ws)`·`rs(Ws)`가 아니다. 전체 저장량, 보수곡선, 투수계수, 독립 건조밀도·질량비열은 이 원문에서 얻지 못했다.

실용적 의미: 별도 **Con-W 대리 시나리오**라면 고정 유효 `Cv`와 `k`로 밀도·질량비열 두 항을 하나로 줄일 수 있다. 그러나 이를 ‘Wang WCC의 확보된 건조 물성’이라고 표시하지 않으며, 저장량 부족은 해결하지 못한다.

## 지지층: 새로운 수문 원저와 접합 제한

[Pham et al. (2025; 온라인 2024), DOI 10.1007/s10163-024-02134-y](https://link.springer.com/article/10.1007/s10163-024-02134-y), [공개 PDF](https://link.springer.com/content/pdf/10.1007/s10163-024-02134-y.pdf). *Unsaturated hydraulic properties of recycled concrete aggregates blended with autoclaved aerated concrete grains for unbound road base materials in Vietnam*.

RCA100%의 Table 2(p.718, PDF p.7), Fig.2(p.719), Table 4(p.723):

| 항목 | 값 | 조건 |
|---|---:|---|
| `Ks` | `1.72×10⁻³ cm/s = 1.72×10⁻⁵ m/s = 61.92 mm/h` | 포화 투수계수; 고정 하단배수 `d₀`가 아님 |
| `θs` | 0.376 m³/m³ | 수문 시편 포화값 |
| 이중모드 `θr` | 0.027 m³/m³ | 공기건조 영역; Table 4는 0.03으로 반올림 |
| `α1, n1, w1` | 0.195 cm⁻¹, 2.243, 0.475 | 이중모드 vG, Table 2 |
| `α2, n2, w2` | 0.00167 cm⁻¹, 1.308, 0.525 | 이중모드 vG, Table 2 |
| 이중모드 `l` | -4.7 | Fig.2의 RCA100% 라벨, `r²=0.81`; 시각 확인 |
| `θ(ψ=-100 cm)` | 0.22 m³/m³ | Table 4의 초기조건 사례; field capacity 정의가 아님 |

비교용 단일모드 Table 2는 `θr=0.170`, `α=0.393`, `n=1.497`이다. 이 `θr`는 습윤구간 적합의 잔류항이므로 공기건조 잔류수로 바꾸어 쓰지 않는다. 단일모드 α 열의 단위는 원문에서 `cm³/cm³`로 인쇄되어 있으나 `α|ψ|` 구조상 역길이가 필요하므로 단위 오기로 판단한다. 이중모드 α 열은 `cm⁻¹`로 명시되어 있다. Fig.2의 RCA 단일모드 `l=-3.3`은 본문의 단일모드 범위 `-1.9~-2.5`와도 어긋난다. 식을 구현할 때 PDF Table 1의 식과 차원·극한을 별도로 검산해야 한다.

수문시험은 250 cm³ 용기, 2673 kJ/m³ 다짐에너지, 18–25 °C 조건이다(Methods, p.715). `K` 실측은 대체로 `|ψ|≈10¹–10³ cm H₂O`; 더 건조한 영역의 `K`는 모형 외삽이다. 상향 재공급을 검증한 WCC+RCA 조립체 시험은 아니다.

**접합 불일치:** [Pham et al. (2026)](https://doi.org/10.3390/constrmater6010010) Table 1은 well-graded RCA의 `ρd=1960 kg/m³`, `φ=0.26`; 수문 원저는 `θs=0.376`이다. 공극 정의·시편 크기·조제 조건의 차이 중 무엇이 원인인지는 확정하지 못했다. 따라서 새 `θr=0.027`을 2026년 회귀 `k=0.37+5.4(θ−θr)`에 바로 꽂거나 `φ=0.26`과 `θs=0.376`을 같은 저장소의 상한으로 함께 설정하지 않는다. 두 원저의 시편 대응이 확인되기 전에는 별도 후보로 유지한다.

산술 점검만 하면 새 원저의 25 cm 층은 포화수량 `94.0 mm`, 잔류항 `6.75 mm`, 그 차이 `87.25 mm`이다. 이는 **해당 수문 시편을 균일한 25 cm로 환산한 값**이며, 기존 공극량 `65 mm`나 실제 증발 가능량으로 취급하지 않는다.

## Wang WCC 원저로 남는 공백

[Wang et al. (2021)](https://pmc.ncbi.nlm.nih.gov/articles/PMC8540386/) Table 1·4·6, §3.1·3.5와 Data Availability를 다시 확인했다.

| 필요한 입력 | 현재 판정 |
|---|---|
| 전체 WCC 건조 `ρ`, `c`, `k`, `ε` | 원문에 완전한 묶음 없음; 골재 `k`와 모체 배합량을 대체값으로 쓰지 않음 |
| 전체 WCC `Ws,max` | 충전재 단독 시험과 요구기준만으로 계산 불가; 모체 공극률·충전량·충전 후 잔존공극 필요 |
| 초기 `Ws` | `500 mL/0.09 m²=5.556 mm`는 살수량; 실제 잔류량·초기 수분량 미측정 |
| `rs(Ws)` 또는 `β(Ws)` | 온도 냉각곡선만으로 다른 열교환항과 분리 식별 불가 |
| WCC의 `ψ(θ)`, `K(θ)`와 계면 | 제공되지 않음 |

원자료는 교신저자 요청으로 제공한다고 적혀 있다. Hu & Sha(2012), *Research on water-holding and cooling concrete design method and its performance*는 Wang 참고문헌 28에서 특정했으나 이번 조사에서 검증 가능한 전문을 확보하지 못해 수치 근거로 추가하지 않았다. Dong(2019)의 semi-flexible asphalt는 재료가 달라 WCC 입력에서 제외한다.

## 네 상태 모델을 단순하게 유지하는 최소 선택

이는 문헌 사실이 아닌 **모델 설계 판단**이다.

- 네 상태의 저장수량 모델에서는 반드시 Richards 방정식이나 완전한 보수곡선을 도입할 필요는 없다. 전체 저장용량, 증발 제한함수, 층간 유량 법칙, 하단배수만 명시해도 보존식은 닫힌다. 다만 현재는 그중 위층의 수치가 남아 있다.
- 고정 하단배수는 사용자가 선택한 `d₀`를 유지하되 `D=min(d₀,Wb/Δt)`처럼 실제 보유수로 제한한다. `Ks`를 `d₀`로 치환하지 않는다.
- 상향 재공급은 `U=0`과 소량 재공급의 비교로 남길 수 있다. WCC와 기층 사이의 모세관 연속성과 계면저항이 확인되지 않았으므로 기층 `K`만으로 실측 `U`를 얻었다고 하지 않는다.
- 현재 즉시 가능한 것은 출처가 명확한 **대리·가정 민감도 실험**이다. Wang 동일배합의 정량 예측으로 진행하려면 최소한 전체 시편의 건조/습윤 질량·부피, 건조/습윤 열물성, 시간별 질량감소+표면온도+기상자료가 추가로 필요하다.

## 검증 기록

신규 공개 PDF 2편을 로컬 참고 폴더에 저장하고, Takebayashi Table 1·4–7 및 Pham Table 2·Fig.2를 렌더하여 원문 열 정렬·재료 이름·지수·단위를 대조했다. 원자료 곡선 디지타이징, 경험계수 재보정, 시뮬레이션 또는 기상 연결은 이 파일의 작업 범위에 포함하지 않았다.
