# 최종 비교 실행 전 준비 기록

2026-09-26, 기준 커밋 425588a. 사용자의 `codex-autonomous-loop auto` 적용.
중간 규모: 기존 네 상태 구조와 기상 연결을 유지하며 입력·실험 조립·실행 잠금을 추가한다.

## 완료 기준과 작업 순서

1. 이전 프로젝트 대화의 모든 접근 가능한 사용자/답변 기록을 읽고 결정·변경·미결정을 복원한다. 원본 대화는 로컬에서 보존하고 Git에는 연구 결정만 남긴다.
2. WCC 계열·지지층·대기 경계의 기존 자료를 재사용하고 핵심 원문·재료 대응·단위만 한 번 제한 점검한다. 확보할 수 없는 같은 WCC 배합의 계수는 대리·가정으로 표기한다.
3. 기계 판독 입력에 출처 ID, 단위, 기본값, 범위, 변환, 한계를 기록한다. 연구 범위 선택은 사용자 답변으로 확정한다.
4. 2025 인천 원본 해시를 대조하고 기상 전처리 및 06시 평가창/사전 72시간 준비창을 정리한다. 비교 조건·민감도·급수와 초기조건을 준비한다.
5. preflight는 입력 생성·스키마·단위·날짜·출처·실행 잠금만 검사한다. 실제 물성+기상의 적분, 온도·냉각·최적량 산출은 금지한다.
6. 관련 단위 테스트, 전체 테스트, 정적 점검과 독립 전체 검토 1회. 수정+재검토는 최대 2회. 통과한 준비물을 commit/push하고 원격 SHA 확인.

## 범위

새 물리모형(Richards, 연속 깊이, 동결)은 도입하지 않는다. 문헌 회귀를 모르는 계수로 재현하지 않는다.
대리 시나리오는 특정 Wang WCC 배합의 검증된 예측이 아니며, 기상 기반 에너지 주분석으로 연구를 임의 전환하지 않는다.
원저 원본은 로컬 참고 폴더와 URL/해시로 보존한다. 저작권 논문 전문이나 전체 개인 대화를 GitHub에 공개하지 않는다.
