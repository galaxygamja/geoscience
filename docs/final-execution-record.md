# 최종 실행·검토 기록

2026-09-26. 준비 완료 커밋 `03804f86b43ff9afb02efe4882ff56d90de9a046`에서 시작했다. 사용자가 “이제 시뮬래아션해서 결과 얻고 끝내자”, autonomous-loop full로 명시 승인했다. 이전의 실행 금지 조건은 그 후속 승인으로 이번 범위에 한해 해제됐다. 승인 전 입력 기록을 소급해서 바꾸지 않았다.

## 실행

- [실행 계획](final-execution-plan.md) 고정 및 독립 읽기 전용 계획 검토. 초기상태 판정 수치, 수렴 합격 게이트, 0일 집단, 공통 날짜와 기준 날짜 분리, 시간별 장부 저장을 보완했다.
- 물리 적분 코드는 변경하지 않았다. 입력·코드·기상 해시를 확인하고 완전한 solver job+소스 해시 캐시를 갖춘 `scripts/run_final_study.py`로 날짜별 병렬 실행했다. 수치 오류는 실패, 동결만 날짜 전체 제외로 처리했다.
- 순서: 20/10/5초 수렴과 초기화 → 게이트 진단 → 기준3×3 → 30시나리오 민감도 → 기준21단계 살수. 수렴·초기화의 기존 결과를 본 계산에서 재사용했다.
- 처음 두 단계의 runner와 이후 수렴 게이트를 요구하는 runner는 각각 해시와 원문을 보존했다. 물리 소스는 같으며 초기 runner는 `results/provenance/runner-before-gate.py`다.
- 초기화 비의존성은168시간 비교에서 통과하지 않았다. 이를 수정하려고 입력이나 날짜를 사후 선택하지 않고 조건부 결과·최적량의 제한으로 명시했다. 수치적 시간 간격 수렴은 통과했다.

## 검증

- `python3 -m unittest discover -s tests`: **55개 통과**. 기존51개와 날짜 짝비교·서로 다른 처리 격자/중복 날짜 거부·동결 전체 제외/수치오류 중단·실패 결과 캐시 방지4개를 포함한다.
- `python3 scripts/check_final_gates.py`: 두 연속 간격 비교의 시간별 Ts 최대차0.010885/0.005434K로0.05K 통과. 온도±3K 영향은0.00052K 미만. 168시간 이력 차이는 조건부 해석 대상으로 기록했다.
- `python3 scripts/verify_final_results.py`: 기록된22,572개 평가 결과에서 질량·에너지 장부를 상태로 재계산하고, 시간별 합·살수 총량·증발잠열 관계·공통 초기상태·처리 격자·121일의 완료/제외 회계·단계 사이 재사용 결과 동일성을 확인했다. 결과 `results/verification.json`.
- 독립 검토자는 모든 평가 시간별 장부를 상태 차로 확인하고, 세분화의 Ts와 입력 기온에서 A를 재계산했다. 저장된 A와 차이0, 여름95/90% 후보와 50일 교집합이 일치했다.
- 표준 과학 도구 matplotlib3.10.8로 PNG/SVG4쌍을 생성했다. 모든 PNG를 열어 축·단위·표본 수·문구·잘림을 확인했다. 반사율-증발-반사 단파 그림은 열별 동일한 y범위를 사용한다. 그림 생성에만 프로젝트 `.venv`의 matplotlib를 추가했고 적분은 표준 라이브러리로 수행했다.

## 독립 검토

계획 검토와 별개 검토자가 전체 신규 실행·분석·그림 코드, 압축 원자료, CSV·그림, 보고서 및 한계 문구를 읽기 전용으로 검토했다. 최종 판정은 **통과, 차단 이슈·수정 요구 없음**이다. 검토자가 독립 재계산한 시간별 장부 최대 잔차는 물1.738×10⁻¹²kg/m², 열2.883×10⁻⁷J/m²였고, 세분화 A의 저장값 대비 차이는0이었다. 온도·증발·반사·상호작용·물/열 장부·민감도 극값과 최종 보고서를 대조했다. 반복 적분 없이 산출물을 검토했고 추가 수정-검토 반복은 필요하지 않았다.

## 연구상 남는 제한

서로 다른 문헌의 물성을 합친 대리계이며 현장 WCC 검증이 아니다. 초기 수분 이력·증발법칙·하향이동에 효과가 의존한다. 95/90%값은 기준 초기화 및 정해진 물량 상한 안의 후보다. 겨울 계절 결론, 반사율의 보행자 최적값, MRT/UTCI/안전 판정, 상한 밖 최적 물량은 얻지 않았다. 이는 계산 누락을 숨긴 것이 아니라 결과가 뒷받침하는 범위다.
