# 반사·증발 복합 포장 시뮬레이션 실행 계획

작성일: 2026-09-22. 상태: 실행 계획 수립, 시뮬레이션 미실행.

## 1. 연구 질문과 범위

연구 제목(안): **인천의 겨울·여름 기상 조건에서 포장 반사율과 초기 수분량이 표면 열수지에 미치는 영향**.

검증할 질문은 다음 세 가지다.

1. 반사율 증가와 수분 공급은 여름철 표면 최고온도 및 기온 초과 온도 누적량을 얼마나 바꾸는가?
2. 복합 조건의 효과는 각 단독 조건의 효과를 더한 것과 다른가? 수분 공급량을 늘릴수록 추가 냉각 이득은 어떻게 변하는가?
3. 같은 조건이 겨울철 표면온도, 영하 지속시간 및 표면층 내부 수분의 동결에 어떤 영향을 주는가?

주 분석 지점은 **인천 ASOS 112**다. 백령도와 강화는 이번 주 분석에 합치지 않는다. 2025년 연간 자료를 입력·품질 점검에 사용하고, 주 비교기간은 **1-2월과 7-8월**로 고정한다. 3-6월과 9-12월의 계산은 주 분석 완료 후 적용 범위를 살펴보는 추가 분석으로 둔다.

해석 대상은 수평의 개방된 가상 포장 1 m²다. 건물 그늘, 도시 협곡, 차량의 열, 대기 흐름의 공간 변화는 기본 모델에 포함하지 않는다. 기온은 관측 입력으로 고정되므로 이 모델로 인천 전체의 기온 저감량을 예측할 수 없다. 반사 복사량은 제시하지만 인체 형상·의복·활동량을 모델링하지 않으므로 체감온도나 UTCI 개선량으로 바꾸지 않는다.

## 2. 현재 자료의 사용 원칙

기존 점검 결과는 `annual-data-review.md`에 있다. 다음 원칙은 기존 점검 문서보다 우선한다.

- 현재 자료로 모델 개발과 제한된 조건의 계절 비교를 시작할 수 있다. 추가 자료 다운로드를 착수 조건으로 삼지 않는다.
- 연간 파일의 인천 시각은 2025-01-01 01:00부터 12-31 00:00까지 8,736개다. 이를 완전한 8,760시간이라고 표시하지 않는다.
- 기존 1-2월 파일로 1월 1일 00시의 공통 5개 변수만 보충할 수 있다. 그 시각의 기압·전운량·지중온도까지 복원되는 것은 아니다. 완전한 초기조건이 필요한 주 분석에서는 해당 날짜를 제외할 수 있다.
- QC 공란을 자동으로 ‘QC 0 정상’으로 바꾸지 않는다. `값 존재/QC 공란`, `QC 오류`, `QC 결측`, `값·QC 충돌`을 별도로 보존한다.
- 야간 일사 공란을 0으로 채우려면 시각이 나타내는 **누적 구간 전체**가 야간인지 확인한다. 일출·일몰 부근 또는 낮의 공란에는 같은 규칙을 적용하지 않는다.
- QC가 깨끗하다는 이유만으로 강수 공란을 무강수로 단정하지 않는다. 강수 기록 방식과 현상번호의 의미를 공식 설명에서 확인한 뒤 판정하고, 근거가 부족하면 `강수 불명`으로 남긴다.
- 적설 공란과 영하 기온만으로 무적설 또는 무결빙을 확정하지 않는다. 눈의 관측 증거가 있는 날, 전일 적설이 남아 있을 수 있는 날, 상태가 불명확한 날을 구분한다.

실측 포장온도가 없으므로 수치 검증과 불확실성 분석을 강화하더라도 실제 포장 성능의 실험 검증을 완료했다고 표현하지 않는다. 기상청 지면온도도 포장온도의 정답이 아니다.

## 3. 단계 1: 원본 보존과 재현 가능한 전처리

### 작업

1. 연간 CSV와 기존 계절 CSV의 파일명, 크기, SHA-256, 인코딩, 지점, 기간을 원본 목록에 기록한다. 원본은 변경하지 않는다.
2. CP949로 읽고 인천 112만 추출한다. 시각은 공식 자료 정의 확인 후 `Asia/Seoul`로 명시하고 정렬한다. 현상번호 등 코드는 숫자로 계산하지 않고 문자열로 보존한다.
3. 지점·시각의 유일성, 매시 간격, 범위 밖 시각, 변수별 결측, QC 충돌을 자동 검사한다.
4. 입력마다 원본값, 사용값, QC, 처리 사유를 추적한다. 주간 일사나 기상변수의 긴 공백을 임의 보간해 주 결과에 사용하지 않는다. 1시간짜리 공백 보간도 별도 민감도 분석으로만 둔다.
5. SI 단위로 변환한다. 기압은 hPa × 100, 습도는 % ÷ 100으로 변환한다. 복사 계산 온도는 K를 사용한다.
6. 일사가 1시간 누적량임을 확인한 뒤 MJ/m² × 10⁶ ÷ 3,600으로 W/m²를 만든다. 하위 계산 간격으로 나눠도 원래 시간별 에너지 총량을 보존한다. 누적 강수도 선형 보간하지 않는다.
7. 기온·기압·수증기압·풍속 등 순간/평균값은 보고 시각 정의에 맞춰 시간 사이를 보간한다. 보간은 관측의 시간해상도를 높이는 것이 아님을 기록한다.
8. 일별 후보표를 만든다. 시간 수, QC 이상, 강수 상태, 적설 상태, 기온 최솟값·최댓값·평균, 일사합, 풍속·습도 평균, 하부 경계자료 가용성을 포함한다.

### 산출물과 완료 기준

- `data/source_manifest.json`, `data/processed/incheon_2025_hourly.csv`, `data/processed/day_catalog.csv`
- `docs/data-dictionary.md`, `docs/preprocessing-rules.md`, 전처리 모듈과 검사 코드
- 중복 0건, 설명되지 않은 시간 이동 0건, 모든 변경값에 사유 존재, 계절 파일과 겹치는 5개 변수 불일치 0건.
- 일사 재분배 전후 시간별 에너지 오차는 부동소수점 허용오차 이내. 제외일과 원인을 모두 공개한다.

원본은 로컬 `data/raw/`에 보존하고 경로·해시·획득 절차를 Git에 기록한다. 원본 공개 배포는 기상자료 이용·출처 조건을 확인한 뒤 결정한다. 개인정보와 서명이 있는 PDF 원본을 자동 업로드하지 않는다.

## 4. 단계 2: 방정식과 물성 확정

### 열수지 모델

깊이 방향 **1차원 다층 열전도 모델**을 유한체적법으로 계산한다. 표면 제어체적과 내부층에 열을 저장하며, 표면의 열저장을 다른 식에 중복 계상하지 않는다.

표면 에너지수지의 부호는 포장으로 들어오는 방향을 양으로 둔다.

`dU_surface/dt = (1-α)K↓ + εL↓ - εσTs⁴ - H - hv(Ts)(E+Es) - G + Qwater`

- U: 면적당 저장 엔탈피(J/m²). 겨울 확장에서는 물·얼음의 잠열을 포함한다.
- α: 반사율, K↓: 관측 하향 단파복사(W/m²).
- ε: 방사율, L↓: 기온·수증기압·운량으로 추정하는 하향 장파복사.
- Ts: 표면온도(K), H = h(Ts-Ta): 공기로 향하는 현열.
- E: 액체 증발 질량유속, Es: 얼음 승화 질량유속. 응결·착상은 각각 음의 유속으로 나타낸다.
- hv: 저장 엔탈피 U와 같은 기준상태로 정의한 수증기 비엔탈피. G: 아래층으로 전달되는 열.
- Qwater: 같은 기준상태에서 계산한 주입·배출수의 엔탈피 유속. 여름 주입수 온도는 기온, 겨울은 max(기온, 1°C)를 초기 시나리오로 두고 민감도를 확인한다. 겨울의 1°C는 액체 급수를 정의하기 위한 설계값이며 실제 공급수 관측값이 아니다. 공급수의 열 유입과 필요한 외부 가열 에너지도 별도로 보고한다.

위 식은 물 질량 변화까지 포함한 총 엔탈피 형식이다. 온도 방정식으로 변환할 때 액체에는 기화 잠열 Lv, 얼음에는 승화 잠열 Ls가 나타나도록 유도한다. 총 엔탈피 식에 Lv·Ls만을 임의로 섞어 질량 이동의 현열을 빠뜨리거나 동결 잠열을 이중 계상하지 않는다. 동일한 기준상태의 질량·에너지 수지로 이 유도를 검증한다.

내부층에는 `∂u/∂t = ∂(k ∂T/∂z)/∂z`를 적용한다. u는 체적 엔탈피다. 기상 조건에 따라 대류·전도의 방향이 바뀔 수 있도록 구현한다.

장파복사는 습도 기반 맑은 하늘 식과 운량 보정을 기본 후보로 삼고, 다른 시간해상도에 맞는 식 하나와 비교한다. 일 단위 장파복사 식을 그대로 매시간 식으로 사용하지 않는다. 풍속 측정 높이와 대류식의 기준 높이를 확인하고 보정·거칠기 불확실성을 남긴다. FAO 기준 잔디 증발산량을 포장 증발량으로 직접 사용하지 않는다.

### 수분수지와 겨울 확장

표면층은 우선 유효 저장수량 W(kg/m² = mm)를 가진 저장소로 단순화한다.

`d(Wliquid + Wice)/dt = I + P - E - Es - D - R`

I는 공급수, P는 강수, D는 배수, R은 용량 초과 유출이다. 주 비교는 무강수 조건(P=0)의 초기 수분 공급 실험이다. 배수·유출·응결이 발생하면 물수지와 해당 에너지를 함께 기록한다. 음수 수분을 계산한 뒤 단순히 0으로 잘라 손실을 숨기지 않는다.

증발은 수증기 차이와 공기역학·표면 저항으로 계산하고 액체 수분 가용량으로 제한한다. 건조될수록 저항이 커지는 관계와 배수 특성은 문헌 근거를 붙인다. 기본 모델은 상세 공극수 이동을 재현하지 않으므로 저항과 보수량을 주요 불확실성으로 다룬다.

겨울의 물 공급 조건에는 **동결·융해 잠열, 액체·얼음 분율, 얼음의 승화/착상**을 추가한다. 겨울 기온에서 액체만 가정한 증발 모델을 그대로 사용하지 않는다. 검증된 동결 확장이 완성되기 전에는 겨울 결과를 건조 조건과 비동결 조건에 한정한다. 공극수 동결량을 노면의 연속적인 빙판 두께나 차량 미끄럼 위험으로 해석하지 않는다.

### 물성 및 경계조건

모든 반사율·수분 조건은 같은 가상 포장 구조를 사용한다. 재료 변경과 반사율 효과를 혼동하지 않도록 기본 비교에서는 재료 구조를 고정한다. 저장된 물·얼음의 열용량과 상변화 잠열은 기본 수지에 반드시 포함하고, 습윤에 따른 유효 열전도율·광학 특성 변화는 별도 확장으로 검사한다.

반사율, 방사율, 열전도율, 밀도, 비열, 층 두께, 최대 보수량, 배수 특성, 증발 저항의 기준값·범위·온도 의존성을 `parameters.yml`과 `parameter-sources.md`에 기록한다. **문헌값, 사용자가 정한 실험 수준, 검증용 가상값**을 구별한다. 물성의 상관관계를 무시한 비현실적인 표본 조합을 만들지 않는다.

하부 경계는 기상청 30 cm 지중온도를 공통 대리 입력으로 쓰는 경우와, 더 깊은 계산영역/온도 경계를 사용하는 경우를 비교한다. 깊이와 층 구조를 일치시키며, 관측 토양온도가 실제 포장 아래의 온도라는 가정은 하지 않는다. 경계조건에 따라 결론이 바뀌면 단일 결과를 확정하지 않는다.

### 완료 기준

- 모든 항의 단위·부호·자료 출처가 확정된다. 문헌을 확인하지 않은 재료 물성을 실제값으로 사용하지 않는다.
- 방정식, 물 공급 시간, 초기조건, 하부 경계, 계산 간격이 설정 파일에 기록된다.
- 간단한 건조 기준 모델을 먼저 통과시킨 뒤 증발과 동결을 순서대로 결합한다.

## 5. 단계 3: 수치 검증

다음 수치는 프로젝트의 **사전 목표 허용오차**이며 물리적 정확도가 입증됐다는 의미가 아니다. 미달 시 원인을 해결하고 기준을 사후에 느슨하게 바꿔 통과시키지 않는다.

| 검사 | 방법 | 완료 기준 |
|---|---|---|
| 단위·부호 | 1 MJ/m²/h 변환, 온도 동일 조건, 양방향 대류·전도 | 예상값과 일치 |
| 전도 | 균일온도 무열원, 정상 선형온도 분포 및 해석해 | 격자 세분화에 따라 오차 감소 |
| 에너지 보존 | 전체 층 엔탈피 변화와 외부 플럭스 적분을 독립적으로 비교 | 일 잔차 / max(절대 외부 교환열 적분, 1 MJ/m²) < 0.1% |
| 물 보존 | 초기물+유입-유출-최종물 | 절대 잔차 < 10⁻⁶ kg/m²/일, 음수 저장량 없음 |
| 시간 수렴 | Δt=300, 150, 75초를 동일한 시간별 관측 입력으로 계산 | 마지막 두 해의 최고온도 차이 < 0.1°C, 누적 증발 차이 < max(1%, 0.001 mm) |
| 공간 수렴 | 같은 물리 깊이에서 표면 부근 격자를 절반으로 축소 | 최고온도 차이 < 0.1°C, 주요 조건 순위 안정 |
| 동결·융해 | 단열 동결/해빙 엔탈피 및 상변화 기준문제 | 질량·잠열 보존, 온도·얼음 분율의 수렴 |
| 초기조건 | 온도 초기값 ±5°C, 예열 3일/7일 비교 | 평가 시작 시 층별 온도 차이 < 0.1°C; 미달 시 예열 연장 |

적분기는 안정적인 음해법을 우선 검토한다. 300초는 시작값이며 검증 결과로 확정한다. 반복해법 수렴 실패나 보존 실패는 결과 파일에 실패로 기록하고 평균에서 조용히 제거하지 않는다.

## 6. 단계 4: 9개 기본 조건과 계절 비교

### 고정 비교 조건

초기 설계 수준은 아래와 같다. 이는 실험용 시나리오 값이며 실제 재료의 확정 물성이 아니다. 단계 2에서 문헌 범위를 벗어나면 본 계산 전에 수정하고 변경 이유를 남긴다.

| 요인 | 낮음/없음 | 중간 | 높음 |
|---|---:|---:|---:|
| 반사율 α | 0.10 | 0.30 | 0.50 |
| 초기 총 수분량 / 최대 보수량 | 0 | 0.50 | 1.00 |

총 3×3=9개 조건이며 α=0.10, 초기 수분 0을 기본 대조군으로 둔다. 보수량이 확정되면 실제 물의 양을 kg/m² 및 L/m²로 함께 표시한다. 반사율만의 효과는 같은 수분량끼리, 수분만의 효과는 같은 반사율끼리 비교한다.

### 하루 실험 절차

1. 기본 반사율의 건조 열모형을 앞선 3-7일의 기상자료로 예열한다. 공통 초기 수분량을 0으로 맞추기 위해 이 예열 단계에서는 수분 교환을 비활성화한다. 이는 실제 노면의 재현이 아닌 초기 열 상태 생성 절차이며, 평가창부터 응결·착상을 포함한 수분 교환을 활성화한다. 기록 시작부는 반복 기상으로 예열할 수 있지만 인위적 예열임을 표시하고 충분히 수렴하지 않으면 해당 날짜를 제외한다.
2. 매일 06:00 KST에서 열 상태를 9개 조건으로 복제한다. 같은 온도 프로파일에서 반사율을 변경하고 정해진 물을 한 번 공급한다. 공급수의 열과 상변화를 보존식에 반영한다.
3. 다음 날 06:00까지 24시간을 계산한다. 추가 물 공급은 하지 않는다. 강수·적설 및 입력 가용성 판정도 이 24시간 창과 필요한 예열창을 기준으로 한다.
4. 하부 경계와 기상 조건을 모두 동일하게 적용한다. 대조군 건조 조건에도 응결이 발생하면 실제 계산 수분을 기록한다.

이는 **공통 초기 열 상태에서 조건을 변경하는 24시간 수치 실험**이다. 장기간 해당 반사율로 운영한 실제 도로의 연속 상태와 구별한다. 기본 분석 이후에는 반사율별로 따로 예열한 지속 운영 조건을 비교해 초기화 방식에 대한 결론의 안정성을 확인한다.

### 날짜 선정과 범위

- 겨울 59일, 여름 62일, 총 121일을 후보로 삼는다. 실제 사용일 수는 전처리·예열·강수·적설 판정 후 확정한다.
- 주 결과는 **유효한 모든 날짜 × 동일 9개 조건**으로 계산한다. 최고기온이 높은 3일만으로 계절 전체를 대표하지 않는다. 최대 기본 평가창은 121×9=1,089개이며 예열 계산은 별도다.
- 여름 고온 3일은 상세 사례 그림으로 사용한다. 현재 후보인 7/26, 7/11, 7/27은 달력 날짜 점검 기준이므로 06~06시 창으로 재검사한 뒤 확정한다.
- 겨울은 유효일 중 일평균 기온 최저일, 기간 중앙값에 가장 가까운 날, 일사합 최대일을 상세 사례로 선정한다. 중복되면 다음 순위, 동률이면 빠른 날짜를 선택한다.
- 강수·적설 판정이 불명인 날짜는 실제 무강수 사례에 넣지 않는다. 사용할 경우에는 별도 **관측 기상에 기반한 강수·적설 없는 가상 포장 실험**으로 명시하고 주 통계와 분리한다.
- QC9 없는 날만 남겨도 무강수 판정 근거가 확보되지 않으면 일강수량 자료가 선택적 보강 대상이 된다. 자료가 없어도 가상 조건 실험과 모델 검증은 진행할 수 있다.
- 계절별 제외일 수·이유·기온/일사 분포를 공개한다. 선택된 맑고 건조한 날의 결과를 모든 날의 효과로 일반화하지 않는다.

## 7. 단계 5: 평가 지표

| 지표 | 정의와 해석 |
|---|---|
| 표면 최고온도 차이 | max(T대조군) - max(T조건). 최고 시각 차이도 별도 기록 |
| 같은 시각 온도 차이 | T대조군(t) - T조건(t). 위의 최대값 차이와 구분 |
| 기온 초과 누적량 | ∫max(Ts-Ta, 0)dt, °C·h. 관측 기온과의 차이며 건강위험 지표가 아님 |
| 야간 현열 방출 | 야간의 양의 H 적분, MJ/m². 음의 H도 별도로 보존 |
| 물 공급·소모 | 공급수, 증발/승화, 응결/착상, 배수, 잔류 액체·얼음을 kg/m²로 분리 |
| 물 사용 효율 | 같은 α의 무공급 대비 누적 온도차 감소 / 공급수. 분모 0은 해당 없음 |
| 복사 변화 | 반사 단파 αK↓와 방출 장파 εσTs⁴ 변화. 보행자 쾌적도 개선으로 단정하지 않음 |
| 겨울 지표 | 표면 최저온도, Ts<0°C 시간, 보유 수분과 영하가 겹치는 시간, 얼음 최대량, 해빙시간 |

복합 효과는 지표 Y에 대해 `Y(α,W)-Y(α,0)-Y(α0,W)+Y(α0,0)`으로 계산한다. Y가 온도인지 냉각량인지에 따라 부호 해석을 명시한다. 상호작용이 없거나 반대 방향으로 나타나는 것도 연구 결과로 인정한다.

계절 평균은 일별 효과를 같은 가중치로 비교하고 중앙값·사분위범위·유효일 수도 제공한다. 겨울의 추가 냉각을 곧바로 ‘개선’이라고 부르지 않는다.

## 8. 단계 6: 실험을 대신할 심화 분석

### 연속 조건 탐색

기본 9조건이 검증을 통과하면 α=0.10~0.50을 0.05 간격(9수준), 초기 수분비=0~1을 0.10 간격(11수준)으로 탐색한다. 대표 6일에서 99×6=594개 평가창을 우선 계산한다. 물을 더 쓰는 조건과 냉각·반사복사·겨울 동결 지표를 함께 비교해 서로 장단점이 있는 조건군을 제시한다.

### 매개변수 민감도와 불확실성

1. 열전도율, 체적 열용량, 방사율, 층 두께, 대류계수 보정, 증발 저항, 보수량·배수, 하부 경계, 장파복사 식을 대상으로 한다.
2. 먼저 기준값과 문헌 하한·상한의 일변수 검사를 수행해 영향이 큰 항목을 찾는다. 계수 범위를 출처 없이 일괄 ±20%로 정하지 않는다.
3. 문헌 범위와 물리 제약을 반영한 100개 공동 표본으로 예비 계산 후 500개로 확대한다. 난수 seed는 2025로 고정한다.
4. 모든 조건에 같은 매개변수 표본을 적용해 짝지은 차이를 계산한다. 대표 6일 × 9조건 × 500표본은 최대 27,000개 평가창이며 짧은 시험 실행으로 실제 소요시간을 먼저 측정한다.
5. 중앙값과 5-95백분위 **모형 불확실성 구간** 및 조건별 우위 비율을 보고한다. 문헌 범위에 임의로 준 분포를 관측에 근거한 95% 신뢰구간이라고 부르지 않는다.
6. 날짜 간 변동과 매개변수 불확실성을 분리한다. 대표 6일의 불확실성 구간을 계절 전체로 일반화하지 않으며, 계절 평균에 통계 구간이 필요하면 연속일 자기상관을 고려한 블록 재표집을 별도로 적용한다.
7. 250→500표본에서 주요 냉각량 분위수 변화 <0.2°C, 우위 비율 변화 <5%p를 잠정 표본 수렴 기준으로 둔다. 미달하면 표본 수를 늘리거나 결과를 미수렴으로 표시한다.

### 관측 및 문헌과의 비교

- 독립된 해석해·보존식 비교로 계산 정확성을 확인한다.
- 지면온도·지중온도는 관측 토양과 가상 포장의 온도 범위·일변화 위상 차이를 이해하는 보조 자료로 쓴다. 가상 포장의 물성을 토양온도에 강제로 맞추지 않는다.
- 관측 토양을 별도 모델링해 비교할 경우 재료와 수분 조건을 따로 정의하고, 매개변수 설정용 날짜와 평가용 날짜를 시간 구간으로 분리한다. 결과를 포장 모델의 실증 정확도로 대체하지 않는다.
- 선행 실험 논문의 입력조건과 결과가 충분하면 별도 벤치마크를 재현한다. 초록의 온도 저감 수치만 맞추는 방식은 쓰지 않는다. 재현자료 부족 시 문헌 비교의 범위를 정성적 타당성 점검으로 제한한다.

- [기상청 ASOS 자료 설명](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do): 자료형태와 QC 정의, 겨울 강수 제공 간격 참고. 변수별 공란·누적구간·시각 정의는 전처리 구현 전에 상세 지침에서 확인한다.

본 계획의 시나리오 수준, 계산 간격, 표본 수, 완료 허용오차는 연구 설계 선택이다. 위 참고자료가 이 숫자들을 직접 권고한다는 의미는 아니다.
