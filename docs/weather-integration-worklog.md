# 2026-09-26 자료 확보와 기상 연결 작업

범위: 기존 네 상태 계산기를 유지하고, WCC·지지층의 누락 원저를 제한적으로 추적한 뒤 실제 인천 시간자료를 입력으로 연결한다. 물성 출처가 없는 값을 자동 생성하지 않는다.

완료 조건:

1. 신규 원저의 재료·단위·건습 기준·적용 제한을 기록한다. 서로 다른 시편의 값을 동일 WCC 실측 묶음으로 만들지 않는다.
2. 기상청 누적 시각·겨울 3시간 강수·빈칸 규칙을 구현한다. QC 결측, 낮 일사 결측, 눈은 실행 차단 사유로 남긴다.
3. 실제 2025년 파일에서 날짜별 입력과 제외 사유를 생성한다. 기상 입력을 계산기에 붙이는 경로와 단위·누적량 보존을 시험한다.
4. 전체 테스트와 독립 통합 검토 1회를 수행한다. 수정·재검토는 최대 2회. 통과 범위와 아직 불가능한 연구 결과를 구별해 커밋·push한다.

중간 규모의 기존 모듈 연결 작업으로 진행한다. 원저 조사 두 건은 서로 독립적으로 수행하고, 루트가 구현·검증·통합을 담당한다. 별도 모델 복잡화, 연속 깊이 해석, 동결 모델 도입은 범위 밖이다.

## 최종 확인

- 신규 원저 2편의 핵심 표·단위·건습 기준을 확인했다. 완성된 동일 WCC 물성은 확보하지 못해 확정 설정을 생성하지 않았다.
- 공식 일강수량 182일을 추가 확보했다. 실제 원본 8,736시간의 해시를 대조했고, 대상 121일 중 눈·결측 등의 제외 사유가 없는 기상 입력 99창을 구성했다. 겨울의 젖은 층 동결 가능성은 별도 모델 적용성 제한이다.
- 전체 테스트 45개, compileall, git diff --check 통과. 실제 기상 + 시험용 가상 재료의 20/10/5초 보존·수렴 결과는 `outputs/verification/weather-integration-final.json`에 기록했다. WCC 냉각 예측이 아니다.
- 독립 전체 검토 1회에서 겨울 비정규 보고 시각의 오류 QC가 무시되는 결함 1건을 수용했다. 해당 3시간 블록을 차단하도록 수정하고 회귀 테스트를 추가했다. 같은 검토자의 재검토 1회에서 추가 발견 없음, 45개 테스트 재통과를 확인했다.
- 사용자가 대리 물성·가정 범위 연구를 선택한 뒤 최선의 방법에 대한 추가 고민을 표현했다. 따라서 대리 WCC 수치를 즉시 확정·실행하지 않고, 기상 기반 에너지 비교를 주분석으로 하고 온도 예측을 보조 민감도로 두는 방향을 설명한다. 모든 자료 확보·WCC 예측 완료라고 표시하지 않는다.
