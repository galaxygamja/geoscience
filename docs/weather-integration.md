# 인천 기상자료 연결 결과와 남은 물성

2026-09-26. **기상 입력 연결은 구현했고 실제 파일로 확인했다. WCC 물성을 전부 확보한 것은 아니다.** 원저 두 편에서 새 수치를 확보했으나 동일 배합의 건조 열용량·저장용량·증발저항 묶음은 여전히 없다. 대리 재료를 WCC 실측값으로 대입하지 않았다.

## 실제 데이터로 달라진 점

기존 엔진 앞에 `src/geoscience/weather.py`를 연결했다. 사용자 원본은 수정하지 않는다. 인천 112만 선택하며 원래 값·QC·처리 이유와 입력 파일 SHA-256이 결과 JSON에 남는다.

| 06시부터 다음 날 06시까지 | 후보 일수 | 24시간 기상 입력 구성 가능 |
|---|---:|---:|
| 2025년 1월 | 31 | 18 |
| 2월 | 28 | 21 |
| 7월 | 31 | 31 |
| 8월 | 31 | 29 |
| 합계 | 121 | 99 |

이는 **물성·초기조건까지 갖춘 실험 가능 일수는 아니다.** 영하의 공기, 차가운 초기층 또는 야간 복사냉각으로 젖은 층이 0°C 이하가 되면 계산기가 중단한다. 겨울을 분석에서 없앤 것이 아니라, 동결을 제외한 모델의 공통 비교창을 별도로 골라야 한다는 뜻이다. `wet_freezing_risk_from_air`는 사전 경고이지 동결의 충분조건·필요조건 판정이 아니다.

예: **2025-07-01 06:00 → 07-02 06:00**, 관측 기반 강수 합계 **0.7 mm**, 일사 합계 **20.31 MJ/m²**가 같은 24시간 입력으로 연결됐다. 날짜·원자료가 실제이며, 이를 읽는 계산기 검증에만 가상 재료를 사용했다. 그 검증의 표면온도를 WCC 결과로 보고하지 않는다.

## 빈칸·시간·눈을 처리하는 규칙

[기후통계지침(2021.5)](https://data.kma.go.kr/resources/images/publication/%EA%B8%B0%ED%9B%84%ED%86%B5%EA%B3%84%EC%A7%80%EC%B9%A8%282021.5%29.pdf) 2.2.1.1 및 부록 A 1.3.5·1.3.7·1.3.18에 근거한다.

- 시간 누적량은 **표기 시각에 끝나는 구간**이다. 일사 MJ/m² × 10⁶/3600 → W/m². 순간 기온·증기압·기압·운량, 직전 10분 평균 풍속은 양 끝 정시값의 평균으로 한 시간 동안 고정한다. 이는 시간 보간 가정이다.
- 11–3월 강수는 직전 **3시간 합계**다. 3으로 나누어 각 시간에 동일하게 배분한다. 총량은 보존하지만 그 안에서 실제 비가 내린 시각을 복원한 것은 아니다. 4–10월은 1시간 합계를 쓴다. 월 경계의 00시는 이전 날의 누적 기간을 따른다.
- 무강수 공란·QC 공란은 공식 표 작성규칙에 따라 0으로 해석한다. `0.0`은 미량 강수를 포함하므로 ‘현상 없음’과 별도로 기록한다. QC 9는 자체로 0이 아니다.
- 추가 수집한 **공식 숫자 일강수량**과 완전한 시간/3시간 보고 격자의 유효값 합계가 일치할 때만 남은 **빈칸 QC 9**를 0으로 보완한다. 일합계와 불일치하면 그 날 강수 입력을 보류한다. 오류 QC 1·숫자와 QC 9가 함께 있는 충돌은 복원하지 않는다. `-`인 일강수량은 미확인으로 둔다.
- 1·2·7·8월의 시간행 기준 479개 강수값이 일합계 대조로 0 배분되어 연결됐고, 3개는 미해결로 남았다. 겨울에는 하나의 3시간 원보고가 세 시간행에 연결되므로 **479개 독립 관측을 새로 확보했다는 뜻이 아니다.**
- 일사 공란은 [NOAA 태양위치 계산](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)으로 한 시간 전체가 일출·일몰 기준(-0.833°) 아래일 때만 0으로 근사한다. 1분 간격으로 확인한다. 황혼의 작은 산란 일사를 무시하는 근사이며 관측값은 덮지 않는다. 낮의 결측과 숫자/QC 충돌은 그대로 보류한다.
- 적설·3시간 신적설은 **0.0도 눈이 보고된 것**이다. 깊이 관측은 구간 양 끝을 확인하고, 신적설은 이전 3시간을 차단한다. 현상번호(국내식)도 부록 A 표 A-4로 해석하여 적설 깊이가 기록되지 않은 눈·진눈깨비·어는비·우박 시간을 제외한다. 공란은 잔설이 전혀 없다는 증거가 아니므로 별도 주의 표시를 남긴다.

공개 일강수량 182일과 월별 URL·해시는 `data/kma_daily_precipitation_2025.json`에 있다. 3·9월은 2·8월 말일의 다음 날 06시까지 연결할 때 필요하다. 76일은 숫자, 106일은 `-` 그대로다. 수집 절차·상세 근거는 [기상 원문 점검](weather-source-search-2026-09-26.md)을 참고한다.

## 새로 연결한 대기 경계식

온도 `T`는 K, 증기압 `e`는 Pa, 전운량 `n`은 0–1이다. 기압은 **현지기압**, 지중온도는 30 cm 관측값이다.

| 입력 | 코드에서 쓰는 식 | 출처와 적용 한계 |
|---|---|---|
| 맑은 하늘 방사율 | `εclear = 1.24 [(e/100)/T]^(1/7)` | Brutsaert(1975). [Long & Turner(2008) §3 식1](https://doi.org/10.1029/2008JD009936)에서 계수와 mbar=hPa 단위를 재확인. 인천에 맞춘 보정은 아님 |
| 구름 보정·하향 장파 | `εsky=(1−0.84n)εclear+0.84n`, `L↓=εsky σT⁴` | Unsworth–Monteith(1975), [Juszak & Pellicciotti(2013) Table5·식1](https://doi.org/10.1002/jgrd.50277)에서 재확인. 원래 월 규모 계수의 시간별 적용, 구름 높이 생략·지역 이전은 근사. 이 논문도 다른 장소 적용 성능 저하를 보고함 |
| 습윤 공기 밀도 | `ρair=(p−0.378e)/(287T)` | 이상기체 혼합식 유도. [FAO-56 부록3 식3-5·3-6](https://www.fao.org/4/X0490E/x0490e0k.htm)의 가상온도 방식과 대응. 분자량비0.622, 기체상수287 |
| 대류 계수 | `hc=5.7+3.8 uloc` | [EnergyPlus Engineering Reference, McAdams 식3.104](https://energyplus.readthedocs.io/en/latest/guides/engineering-reference/3.5-outside-surface-heat-balance.html). 출처계수이지만 실제 거칠기·풍향·안정도를 분해하지 않는 단순식 |
| 공기측 증발 저항 | `ra=ρair·1013/hc` | 현열 저항식의 대수적 변환. 공기 비열1013 J/(kg K)은 FAO-56 부록3. 수증기와 열의 전달 저항을 같게 놓는 **추가 근사**이며 WCC 내부 증발저항은 별도로 필요 |

`uloc = wind_factor × 관측풍속`. **계수 1은 검증용 기준 시나리오이지 2025년 인천 관측풍속이 포장 바로 위 풍속과 같다는 측정 결론이 아니다.** CLI에서 반드시 직접 지정하며 결과에 남긴다. 2025년 풍속계 설치 높이와 대상 포장 주변 지형·차폐는 확인하지 못했다. 본 실험에서는 이 계수와 대류식을 민감도 대상으로 두거나 실험 장소 정보를 확보해야 한다. 또한 관측소 맨땅의 30 cm 지중온도는 하부 경계의 대리값일 뿐, 시뮬레이션 지지층 온도의 검증 자료가 아니다. `insulated` 비교도 선택할 수 있다.

## 실행 방법

저장소 루트에서 실제 원본 경로를 지정한다. `--output`은 기존 파일을 덮어쓰지 않는다.

```sh
python3 -m src.geoscience.weather \
  --annual '/실제/2025년_시간단위_전체데이터.csv' \
  --daily data/kma_daily_precipitation_2025.json \
  --wind-factor 1 --deep-boundary observed_30cm \
  --output outputs/weather/incheon2025.json
```

물성·초기상태·증발저항·층간교환을 갖춘 **별도 재료 JSON**에 기상을 붙이는 경로:

```sh
python3 -m src.geoscience.simulate /실제/재료설정.json \
  --weather outputs/weather/incheon2025.json \
  --start '2025-07-01 06:00' --hours 24 \
  --output outputs/실험결과.json
```

재료 JSON에는 `intervals`를 넣지 않는다. 기존 급수 스케줄을 기상이 덮어쓰는 실수를 막기 위해 이미 구간이 있는 입력은 거부한다. 현재 연결은 무추가급수이며 초기 수분은 재료 실험 설정에 남는다. **이 저장소에는 확정 WCC 재료 JSON이 아직 없다.**

## 검증과 남은 결정

`python3 -m unittest discover -s tests -v`와 `python3 scripts/verify_weather.py --annual '/실제/원본.csv' --output outputs/verification/weather-proof.json`으로 재현한다. 후자는 원본 해시까지 확인하며 **실제 기상+가상 재료를 이용한 코드 연결 검증**만 한다.

2025-07-01 06시 창에서 20/10/5초 간격으로 실행했다. 물수지 오차 최대 `2.1×10⁻¹² kg/m²`, 에너지 오차 최대 `7.6×10⁻⁷ J/m²`. 최종 온도의 연속 간격 차이는 `0.000211 → 0.000105 K`로 감소했다. 이것은 구현의 보존·수렴 확인이며 실제 WCC 온도 정확도의 증거가 아니다.

재료 쪽 새 근거는 [WCC 후속 원저 기록](wcc-source-search-2026-09-26.md)에 있다. Con-W의 유효 열물성은 건조 기준이 아니고, 새 RCA 수문 시편의 포화수분량은 기존 열물성 시편의 공극률과 다르다. 둘을 그대로 조립하면 물 열용량 중복·저장 상한 모순이 생긴다.

다음 단계에서 필요한 선택은 **대리 물성·가정 범위로 반사/증발의 비교·민감도 연구를 할지**, 아니면 **선택한 WCC 동일 배합의 정량 예측을 위해 저자 원자료를 확보할지**다. 전자는 진행 가능하지만 모든 상수가 해당 WCC의 실측이라는 주장을 내려놓아야 한다. 후자를 대신해 저자에게 연락하는 일은 별도 승인 없이 수행하지 않았다.
